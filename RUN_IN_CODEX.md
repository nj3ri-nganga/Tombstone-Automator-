# Hybrid logo retrieval in Codex

Run offline tests with `python -m unittest discover -s tests -v`.
Normal retrieval: `python -m tag_logo_bank input.xlsx enriched.xlsx`.
Install the optional SVG wheel with `python -m pip install --only-binary=resvg_py -e ".[svg]"`.
No Cairo/GTK or system rendering stack is needed.

The managed cloud proxy remains unreachable in this thread. Do not bypass it or
claim mocked data as live success. The public GitHub Actions pilot runs the exact
15-company public list on Windows/Linux and retains actual PNGs and source logs.
Inspect report.json and contact-sheet.png before making company-specific success
claims. The full TAG workbook is not present; no confidential data is committed.

optional web search, 429 cooldowns and local resume/cache behavior.
